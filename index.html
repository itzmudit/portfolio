I'm Mudit. I work where electronics meets software, and I like taking an idea from a textbook, or a problem I run into, and turning it into a tool that actually runs.

With my SDF Lab team I turned nodal analysis into MiniSPICE, a DC circuit solver written in C. At Hackin' Summer 2026 I built CaughtBot, which fires 40 prompt-injection and jailbreak attacks at an AI chatbot, scores how many get through, and then hardens it. I also built the frontend for RoadSentinel, a road-health prediction system, at Smart India Hackathon 2026. Next up is MiniSPICE v2, which moves from plain nodal analysis to modified nodal analysis so it can handle voltage sources properly.

CaughtBot

        
Catches a chatbot's weaknesses before attackers do. It attacks the bot, has a second AI judge every reply, writes a report, then rewrites the bot's instructions until its security score goes up.

        
    
          
  • 40 attacks in 6 categories: prompt leakage, instruction override, role-play jailbreaks, off-limits actions, encoding tricks (Base64, leetspeak) and persona unmasking
    • 
          
  • An AI attack generator writes new attacks tailored to each bot's own instructions
    • 
          
  • An LLM judge returns a checked verdict for every reply: whether it worked, the quote that proves it, and how severe it was
    • 
          
  • Auto-harden keeps a fix only if the measured score improves. Accounts, admin dashboard and PDF reports included
    •

MiniSPICE, live

          
The same algorithm as my C program: nodal analysis builds the conductance matrix, then Gaussian elimination with partial pivoting finds every node voltage. Change any resistor and it re-solves instantly. Node 0 is ground.
